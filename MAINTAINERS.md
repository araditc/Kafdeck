# Maintainers

Kafdeck is currently maintained by the Arad ITC project team under the governance defined in `GOVERNANCE.md`.

Named maintainer roles and CODEOWNERS assignments will be added during Phase 0 repository configuration before implementation work is allowed to merge.

## Maintainer responsibilities

Maintainers are responsible for:
- protecting the approved architecture and engineering baseline,
- ensuring required CI/review gates are enforced,
- triaging contributions and security reports,
- keeping roadmap and compatibility documentation current,
- recording material approvals and decisions in the repository.
