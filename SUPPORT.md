# Support

Kafdeck is an open-source project. Public support channels will be documented as the community infrastructure is enabled.

## Bugs and feature requests

Use GitHub Issues once issue templates are enabled. Include reproducible details, affected version/commit, environment, and relevant logs with secrets and sensitive Kafka data removed.

## Security issues

Do not report exploitable vulnerabilities in public issues. Follow `SECURITY.md`.

## Commercial support

No commercial support commitment is implied by the open-source repository. Any future commercial support offering will be documented separately and will not alter the Apache-2.0 rights of the open-source project.
