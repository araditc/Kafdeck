## Scope and support boundaries

W71 R1–R6 acceptance is detailed in the [G5 ledger](../implementation/v0.8-g5-acceptance-ledger.md). The executable inverse is an already-owned NotificationSubscription Active/Paused metadata toggle with fresh source/CAS/authorization and independent critical approval. It is not deletion recovery, ownership transfer, configuration restoration or recall of delivered notifications. Terraform destroy and unadmitted declarative families remain unsupported; MCP stdio effects remain explicitly enabled and backend-governed.

Physical provider fixtures do not certify every SaaS tenant. Browser API fixtures and genuine identity/effect tests are separately identified. Three-OS loopback tests and Linux/Windows/macOS cross-built Terraform ZIPs do not establish full runtime acceptance on every OS/architecture. Provider-dependent rate/throughput views remain Unknown/Unsupported without admitted observations.
