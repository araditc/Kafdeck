## Evidence collection

Use [the publication packet guide](v0.8-publication-packet.md) and
`scripts/release/assemble-v08-readiness.ps1`. Main mode rejects mixed source SHAs,
PR evidence substituted for main, failed jobs, missing gates, skipped selected
acceptance, absent provider proof or missing exact-build SBOM/provenance. It emits
an incomplete packet with a nonzero exit when evidence is missing. Empty cells,
old accepted workstreams and source-only interfaces cannot be relabelled Supported.

The nonpublishing image fixture must build once, identify that exact image, generate
its SPDX SBOM and scan, and run its `/healthz`/frontend checks with networking
disabled. Preserve the offline image archive/hash and build metadata. A local JSON
provenance statement is not a keyless signature; G6 retains its signing obligations.

## Publication decision remains separate

G5/W71 can close after R1–R6 pass and all upstream scope is accepted, without
inventing owner publication permission. Close #209 only after that reconciliation.
Then the owner may authorize publication of one immutable main SHA and its exact
artifacts. PR review, a green packet and a candidate package version do not authorize
a tag, GH Release, GHCR upload or promotion. No v0.8 publication has occurred here.
