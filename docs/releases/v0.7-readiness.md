- deployment access token is accepted from the URL fragment into page-memory state only and scrubbed from browser history immediately;
- governed mutation requests use the same memory-only deployment-token path;
- no runtime CDN script or stylesheet;
- local Tabler and Kafdeck assets;
- provider origins configured server-side;
- no required public provider discovery;
- local OpenAPI/docs availability.

Frontend regression tests enforce no persistent browser-storage calls in application source and no external runtime CDN dependency in the entry document.
