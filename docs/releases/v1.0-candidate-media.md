The [preparation workflow](../../.github/workflows/v1-candidate-media.yml) reads these successful main runs, checks the source and GitHub artifact ZIP digests, validates the media against producer evidence and writes a sorted SHA256 inventory. Download `v1-candidate-full-distribution` to obtain the packages and manifest. The smaller `v1-candidate-manifest` artifact and the SHA256 in the run summary are available for owner review.

With Python 3.11 or later and the reviewed repository checkout, verify the downloaded packet using the independently selected digest:

```sh
python scripts/release/v1_media.py verify staging --manifest-sha256 <approved-manifest-sha256>
```

For signing, an authorized owner dispatches the reviewed workflow from protected main with the manifest SHA256 and the statement `SIGN v1.0.0-rc.1 full-distribution FROM <source> MANIFEST <sha256>`. The workflow assembles the same producer bytes, checks the digest, signs the manifest and verifies the Sigstore bundle with networking disabled. Retain the full distribution, signature bundle, workflow revision and independently obtained trust-root hash together. Official publication and installed operator acceptance are tracked in [V1-7](https://github.com/araditc/Kafdeck/issues/469). A stable version change requires builds with the new embedded version.
