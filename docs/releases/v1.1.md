Start with the [installation and upgrade guide](../operator/v1.1-installation-guide.md) or [Fleet quickstart](../operator/v1.1-fleet-quickstart.md).

## Released capabilities

Fleet adds pinned SSH host registration, verified broker-to-service mappings, bounded service logs, remote installation and upgrade of a staged Java monitoring agent, governed dynamic broker configuration with readback and restore, and recovery of interrupted broker operations. Acceptance covered Linux with systemd and Docker absent, plus an approved isolated Compose pilot on the Arad Office host. [Fleet scope](../rfcs/0011-v1.1-broker-host-management.md) · [Operational acceptance](https://github.com/araditc/Kafdeck/issues/489).
