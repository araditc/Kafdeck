## Supplementary Windows installation and upgrade

The release additionally provides a separately checksummed Windows installer and Java agent bundle. The installer embeds the exact signed win-x64 runtime archive and includes Java 21, PostgreSQL, Keycloak and Windows Services. `Install-Kafdeck.ps1` handles a fresh server and `Upgrade-Kafdeck.ps1` handles the supported existing Windows Services layout with a verified cold backup and automatic recovery. The supplementary installer scripts/vendor media are outside the original signed manifest's scope.

## Acceptance boundaries

Successful 0.9, RC, stable-native and operator acceptance evidence is reused with its original source identities. KAF-02 requires deployment-tested egress.
