# v0.2 Release Readiness Evidence

- **Scope:** Operator Identity and RBAC
- **Release status:** NOT RELEASED — readiness evidence only
- **Release gate:** separate explicit release decision

## Workstream evidence

W12 establishes identity/access-mode contracts. W13 provides OIDC session handling. W14 provides immutable default-deny authorization policy evaluation. W15 enforces authorization in API/UI. W16 adds security audit and hardening. W17 integrates documentation, tests and readiness evidence.

## Security/read-only invariants

- no Kafka mutation route/control,
- no record produce/consume/payload browser,
- deployment token is not operator identity,
- OIDC mode cannot fall back to Token-mode authentication,
- authorization is backend-authoritative and default-deny,
- secret/OIDC token/session-cookie material is excluded from API/log/audit,
- Kafka ACL denial remains distinct from Kafdeck RBAC denial.

## W17 release-candidate gates

The W17 exact head must have all applicable quality, Kafka compatibility/integration, dependency, CodeQL and supply-chain checks green; independent review must be current for that exact head; required review threads must be resolved.

Passing W17 does not itself publish v0.2. Version/tag/release publication requires the separate release gate.
