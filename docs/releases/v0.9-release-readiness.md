## Final local W80 evidence

Actual W80 tests may originate on an identified local Windows fixture. Their
admission is an explicit owner-reviewed local attestation, not a GitHub producer.
Do not mark the packet complete before running released-v0.8 to the actual final
signed candidate, interruption/backup/physical restore/fence/resume, and the
disconnected authenticated journey with staged local identity/broker dependencies.
Prepublication startup tests alone do not prove those journeys.

The optional `w80_packet_base64` input is the base64 of the exact reviewed JSON
bytes (maximum 64 KiB encoded). Its public evidence whitelist is:

| Field | Required value |
| --- | --- |
| `schemaVersion`, `authority` | `1`, `owner-reviewed-local` |
| `sourceSha`, `signedManifestSha256` | Exact final main source and signed manifest digest |
| `baselineSourceSha` | Released v0.8 `cbedd025ab97db10fb21407ea5188c08d6a4d8ce` |
| `candidateWindowsApiArchiveSha256` | Hash of `native/win-x64/kafdeck-api-ui-win-x64.tar.gz` in the signed manifest |
| `testHost` | Nonempty `id`, `os`, `architecture`; identify the actual fixture host |
| `scripts`, `evidence` | Nonempty lists containing only relative public `path` and exact `sha256` of reproducible scripts/raw evidence retained for owner review |
| `disconnectedFixtureOnly` | `true` only after proving staged local dependencies and blocked external egress |
| `checks` | Actual boolean results for all checks below |

Required check names are `sqliteReleasedV08Upgrade`, `sqliteBackupRestoreRollback`,
`sqliteInterruptedMigration`, `postgresReleasedV08Upgrade`, `postgresPhysicalPitr`,
`postgresInterruptedMigration`, `generationFenceUnknownResume` and
`disconnectedAuthenticatedJourney`. False or absent results remain missing gates.
No additional packet/host/evidence fields are accepted; keep credentials, logs
with secrets and private absolute paths outside the public decision artifact.

Compute the SHA256 of the original JSON bytes before base64 encoding. Both
original and triggering dispatch actors must be configured release owners, and
`w80_owner_approval` must exactly say:

```text
ACCEPT W80 <raw-packet-sha256> FOR <source_sha> MANIFEST <manifest_sha256>
```

Owner review corroborates the actual named local raw artifacts; JSON booleans
alone are not execution proof. The raw artifacts and reproducible scripts must
be retained under the reviewed hashes for independent audit.

Absent/incomplete W80 evidence produces `releaseReady: false` and an explicit
`missing` list. The gate returns failure and retains `release-decision.json` with
its SHA256. Only complete signed media, enforced admitted budgets and complete
owner-reviewed final W80 acceptance produce `releaseReady: true`. This exact-source
decision packet authorizes no tag, registry publication or GitHub Release; the
owner's separate publication decision remains necessary.
