# Kafdeck v0.9 candidate

This candidate prepares the governance and enterprise hardening work tracked in [W72–W82](https://github.com/araditc/Kafdeck/issues/425). GitHub Releases records the published version.

- Governance and platform flows cover catalog, policy, requests and attribution.
- Operator UI work includes route admission and English and Persian accessibility journeys.
- Distribution work includes digest-bound OCI and Helm artifacts and an offline validation path.

Review the [distribution and recovery plan](../operations/v0.9-distribution-recovery.md) before upgrading from v0.8. Use the admitted release evidence for supported platform cells, signed media and the upgrade and restore procedure.

The release decision is tracked in [W82](https://github.com/araditc/Kafdeck/issues/436).
