## 1. Release boundary

v0.3 introduces bounded, separately authorized Kafka record inspection under the released v0.2 identity/RBAC boundary.

Release invariants:

- no Kafka mutation,
- no produce/replay,
- no consumer-offset mutation,
- no payload persistence/indexing by default,
- no unbounded whole-topic scan,
- no arbitrary server-side JavaScript,
- no general-purpose SQL stream engine,
- no masking bypass,
- metadata permissions do not imply `record.read`,
- `record.export` is separate,
- server-side masking fails closed,
- Schema Registry is read-only decoding support only.
