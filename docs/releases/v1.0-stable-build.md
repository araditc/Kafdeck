# Preparing the stable 1.0.0 distribution

The [stable build selection](../../.github/release/v1.0.json) sets the native API/UI, CLI, MCP, frontend and Helm versions to `1.0.0`. Terraform retains its independent version `0.8.0`. The previous RC has its own [selection](../../.github/release/v1.0-rc.json), source and signed manifest.

Use the successful native, OCI/Helm and integration producer runs for **one protected-main commit**. Supply their run IDs in that order to the preparation workflow:

```sh
gh workflow run v1-candidate-media.yml --ref main -f stable_runs=NATIVE_RUN,OCI_HELM_RUN,INTEGRATION_RUN
```

Download `v1-candidate-full-distribution` and `v1-candidate-manifest` from the resulting run. The manifest records the product commit, build-input hash, producer ZIP digests, filenames, sizes and SHA256 values. Use the manifest SHA256 from the preparation log to verify the files offline with the reviewed checkout:

```sh
python scripts/release/v1_media.py verify staging --manifest-sha256 APPROVED_SHA256
```

For owner review, retain the two OCI configuration digests from `media/oci/*/oci-native-startup.json` alongside the manifest. These identify the image configurations inside the offline archives. Registry manifest digests must be obtained from the publication transport. After explicit signing authorization the workflow accepts the same producer IDs, the approved SHA256 and the statement `SIGN v1.0.0 full-distribution FROM SOURCE MANIFEST SHA256`. Publication is a later decision.
