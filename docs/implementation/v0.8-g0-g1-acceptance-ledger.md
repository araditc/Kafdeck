## G1 laboratory boundaries

Use only disposable local test identities, keys and databases. Keep downloaded
runtimes, generated trust/credentials and raw execution output under ignored
`deploy/dev/.generated/` or `artifacts/`. Never commit tokens, private keys,
client assertions or credential-bearing configuration.

The Webhook fixture must exercise an actual socket and TLS handshake, the
production transport and worker, and SQLite durable recovery. A test-only dialer
may map an otherwise approved public-IP pin to loopback; this does not prove public
DNS, cloud egress, PostgreSQL/HA or external SaaS provider delivery. Production
SSRF restrictions and certificate validation must remain enforced.

The identity fixture must exchange a real asymmetric private_key_jwt assertion
with an actual pinned Keycloak process, validate its HTTPS discovery/JWKS and
access token in the Kafdeck host, and prove current registered-principal AND
backend RBAC allow/deny behavior on existing versioned GET endpoints. A locally
signed imitation JWT is insufficient evidence.
