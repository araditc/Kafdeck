## Experimental browser endpoint

`GET /api/v1/auth/navigation?clusterId=<logical cluster ID>` is mapped only with OIDC browser session endpoints. It returns `clusterId` and independent boolean fields `ownershipCatalog`, `governancePolicy`, `serviceRequests`, `governanceAttribution`. It calls the same current authorization service used by destination routes, including resource `active` for pages that read it on entry. It makes no provider/storage/effect dispatch and returns no entity names or secrets.

- A normalized OIDC browser session is required; anonymous and non-browser identities receive 401. A locally revoked/disabled managed session receives 403.
- `clusterId` is required, nonblank, at most 256 characters, without control characters; invalid input receives 400. Input is a logical scope, not proof of a configured or reachable Kafka cluster.
- Responses are `Cache-Control: no-store`. It is a read-only GET and requires no CSRF write token. The browser uses `cache: no-store`, caller cancellation and an encoded query. A rejected hint does not manufacture a new session or grant.
- This is an **Experimental first-party browser contract**, alongside the existing session endpoint, not a Stable public REST/Bearer/CLI/MCP interface. It is outside the finite setup/users/connections catalog admitted in G03; that catalog is not relabeled or silently expanded.

## Presentation behavior

The shell binds a hint to the verified session key and exact selected cluster; aborted/late responses cannot publish into another scope. Missing hints fail closed. Session invalidation and cluster selection discard the previous hint. Only admitted pages appear in the menu. Command Palette keeps unavailable commands visible and disabled, using the same menu selection and existing dashboard aliases. It does not navigate denied commands to an unrelated page.

A direct Governance hash retains its requested page title and presents an unavailable status until the matching capability is available; the denied panel does not mount or issue Governance requests. An external scoped read can still enter its page. Changed session authority removes the prior panel. This finite navigation fix does not add general managed Governance support or redesign all role-dependent tools.
