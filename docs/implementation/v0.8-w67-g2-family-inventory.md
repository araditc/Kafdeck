TopicCreate is the first controlled effect vertical because it already has a
typed planner, immutable preview, durable operation repository, existing current
requester guard, provider preconditions and an actual execution handler. Its
admission does not authorize record writes, arbitrary connector configuration,
ACL/SCRAM changes or another effect family. TopicDelete is separately implemented
as the second, always-CRITICAL family, pending its own physical acceptance proof.

The preview binds the current policy fingerprint as well as exact initiating
principal. A changed policy requires a new preview; a plan is never a grant.
Current registration and direct permissions are checked again before provider
effect. Existing `AwaitingApproval`, `ExecutionUnknown`, conflict and expiry
states retain their domain meaning. Unknown effects never authorize replay.
