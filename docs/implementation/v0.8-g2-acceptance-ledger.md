## Evidence boundaries

- Protocol fixtures use actual TCP/TLS and the production transport. Test-only
  dialing maps an approved public-IP pin to a local listener; it does not prove
  public DNS, cloud egress or receipt by an external SaaS account.
- The human acceptance driver uses the real Keycloak authorization endpoint and
  HTML login form, then the real loopback callback and token endpoint. It does not
  use password grant or locally fabricated access tokens. Graphical browser launch
  and human interaction are a separate compatibility case.
- PostgreSQL tests must have an actual configured server. New G2 proof tests skip
  explicitly without it; CI additionally requires generated sanitized evidence.
  Store coordination proof is not automatically physical sender-host HA proof.
- A single-node Kafka laboratory proves the selected real effect. It is not Kafka
  HA, SASL/TLS, or a replacement for the declared Kafka compatibility matrix.
- Generated runtimes, private keys, TLS passwords, human passwords, raw responses
  and databases remain in ignored directories. Committed evidence contains safe
  status, bounded counts, runtime versions, test identifiers and limitations only.
