## Planning answers

### Can telemetry export protected payloads?

No. Raw records/generated payloads/ksql rows/secrets are prohibited signal content.

### Can Prometheus labels include every topic/group/connector by default?

No. Resource identifiers are restricted opt-in bounded dimensions.

### Is historical metrics storage mandatory?

No. Live metrics operate without it.

### Can alerts execute mutations directly?

Not merely because an alert fired. Any admitted alert-driven effect enters ordinary governed operation flow.

### Can CLI/Terraform/MCP bypass approval?

No.

### Can Terraform apply block waiting for a human?

It may expose AwaitingApproval and require the operator/workflow to complete approval through Kafdeck. Synchronous infrastructure-tool expectations do not weaken Kafdeck approval.

### Does MCP trust model/prompt output?

No. Model output is untrusted input.

### Is rollback generic?

No. Only explicit safe inverses are compensatable.
