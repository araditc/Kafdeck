## Security and operational contracts

The API admits closed DTOs for TopicAlter and TopicIncreasePartitions over the
existing planners, risk floors and current actor/policy/provider checks. Named
configuration keys are bounded and validated by the backend; arbitrary provider
commands remain unavailable. Cancel retains exact requester authority; reject
retains distinct registered human approval authority. Unknown/executing/terminal
effects cannot become cancellable provider retries.

The optional notification interlock pins a bounded external file by SHA256 and
requires its active generation to match a separately offline-provisioned database
generation. Startup does not create/enroll/advance that generation. A missing,
malformed, quarantined or mismatched anchor refuses startup, claims and every
concrete physical transport. Operators must physically fence old senders and
rotate the external anchor before declared restore. A restored backup cannot
approve its own generation advance. Existing deployments without this optional
guard do not gain stale-backup replay safety.

The laboratory never reformats existing data or restarts a fenced old primary.
Fresh per-scenario directories retain backups, failed setup attempts, fencing,
promotion and restore metadata. Credentials remain in ignored private files;
only bounded sanitized evidence is eligible for commit/upload. Production
notification HA activation remains closed.
