# G2 real provider laboratory

The integration tests run the shipped API and CLI against real providers. Human
authentication uses the prepared Keycloak authorization endpoint and PKCE S256;
the fixture never makes access tokens or uses the password grant.

| Provider | Local version | Readback |
| --- | --- | --- |
| Apache Kafka | 4.3.1 | Produced bytes, committed consumer offset, purge low watermark and group absence |
| Confluent Schema Registry | 8.3.2 | Registered version, compatibility and deleted subject absence |
| Kafka Connect | 4.3.1, distribution FileStream plugin | Configuration, status, failed task, finite restart activation and connector absence |
| PostgreSQL | Native isolated instance | Independently reopened durable operations and distinct human approval |
| SQLite | Separate owned files | Independently reopened durable operations and recovery source inventory |

The local Schema Registry archive is downloaded from
`https://packages.confluent.io/archive/8.3/confluent-community-8.3.2.tar.gz`.
The SHA512 pinned by `extract-schema-registry-g2.py` was recorded from the first
official HTTPS retrieval; it is not claimed as a separately published checksum.
The extractor materializes only bounded selected runtime files and in-archive
aliases, including Windows compatibility for upstream symbolic links.

Prepare fresh Kafka directories with `prepare-kafka-g2.ps1`. Optional broker and
controller port parameters permit a second, physically distinct cluster; existing
storage is never reformatted. `start-provider-families-g2.ps1` takes explicit
Java/Kafka/Schema Registry runtime paths and a fresh output directory. It admits
numeric loopback only, records process identity and stops only those recorded
processes. Retained laboratory directories contain private configuration and
must not be uploaded.

The provider CLI test requires these explicit environment variables:

```text
KAFDECK_KEYCLOAK_G2_LAB=<prepared private lab.json>
KAFDECK_G2_KAFKA_BOOTSTRAP=127.0.0.1:19092
KAFDECK_G2_SCHEMA_REGISTRY_URL=http://127.0.0.1:18081/
KAFDECK_G2_CONNECT_URL=http://127.0.0.1:18083/
KAFDECK_TEST_POSTGRES=<private disposable connection string>
KAFDECK_G2_EVIDENCE_DIRECTORY=<owned evidence directory>
```

`V08G2ProviderFamilyCliLiveTests` requires both persistence providers. A missing
provider is not substitute acceptance. Linux CI provisions actual pinned provider
versions and requires the two evidence files in addition to the TRX result.
Native Windows Kafka topic deletion is excluded from local acceptance because its
open-file rename behavior can kill the broker; Linux CI separately requires the
actual two-human topic deletion scenario.

Only sanitized `*-evidence.json` and TRX files are publication candidates. Private
keys, passwords, configuration, authorization URLs/codes, tokens, raw provider
replies and broker/database storage are excluded. An intermediate failed run or
an unmerged source checkpoint does not establish protected-main G2 completion.
