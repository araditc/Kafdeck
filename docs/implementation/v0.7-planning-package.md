## Explicit planning answers

### Are generic provider proxies allowed?

No.

Schema Registry, Connect and ksqlDB use exact configured origins and typed Kafdeck-owned routes. Caller-supplied provider URL/path/method forwarding is outside scope.

### Can automation bypass user governance?

No.

Every future external effect revalidates current authority/policy/capability/budgets. There is no immortal browser-session authority.

### Can Connect lifecycle bypass the v0.6 MM2 block?

No.

All effect-capable Connect lifecycle routes share the replication semantic classifier/guard.

### Can replay/generation become an unbounded data plane?

No.

Every job is finite. Hard record/byte/rate/duration ceilings have no unlimited setting and survive restart/failover.

### Does v0.7 admit persistent ksql DDL/DML?

No.

The query/editor is bounded and read-oriented. Persistent queries and DDL/DML are blocked.

### Does v0.7 admit runtime plugins?

No.

New SerDes use internal controlled extension ports. Public plugin loading remains separately approval-bound.

### Are raw payloads/secrets durably stored for jobs?

No by default.

Durable state holds safe checkpoints/counters/fingerprints, not raw record/generated/query data or connector/provider secret bytes.
