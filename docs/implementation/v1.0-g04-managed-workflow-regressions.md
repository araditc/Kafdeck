## Implementation boundary

The only runtime change is an **internal optional owned MemoryCache input** on `RegisteredKafkaRuntime`; normal construction still creates the same bounded 128-entry cache and retains the fixed 30-minute absolute lifetime. It permits testing real expiry with a controlled cache clock, rather than reflection or a 30-minute sleep. No production clock/configuration flag, public contract, permission, role mapping, target limit or cache-admission behavior changes. This does not close qualified Q01 capacity/admission work.

Tests use real loopback ASP.NET routing/CSRF, private state files/file locks, the real cache and actual Data Protection encryption. Synthetic browser principals and Keycloak response handlers are controlled; Kafka metadata is controlled and the lease tests open configurations, not a real broker connection. File/key-ring reopening tests are not a released-v0.9-to-v1.0 binary upgrade/restore, which remains G06/V1-4. Existing G1 real-provider and broader released acceptance evidence retains its original scope; automatic PR CI provides changed-source checks.

Temporary build outputs stay in a task-owned directory on the other authorized C workspace and are removed after completion. Test results and source-bound summaries remain under ignored artifacts. Existing data, running services, signed v0.9 bytes and original evidence are preserved.
