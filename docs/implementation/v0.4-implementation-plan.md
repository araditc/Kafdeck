## Merge discipline

Each workstream:
- starts from the latest stable prerequisite head,
- keeps Issue #100 reconciled,
- uses DCO-compliant commits,
- requires fresh exact-head applicable checks after source changes,
- resolves substantive review threads,
- merges only when repository governance permits and with `expected_head_sha`.

If a review gate blocks merge, dependency-valid stacked work may continue without fabricating approval.
