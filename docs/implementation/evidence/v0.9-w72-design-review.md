| Design concern | Disposition in proposed package |
|---|---|
| Existing direct routes could bypass a new request controller | ADR-0010 requires shared effect-boundary gate for every client and direct route; W74 R2/W75 P3 negative effects mandatory. |
| Long-lived business approval could silently refresh expired material | Immutable operation/revision binding, NeedsReplan, fresh preview/new revision and invalidated old approvals; explicit product and recovery scenarios. |
| Catalog or policy assignment could grant privileges | Descriptive metadata only; policy outcomes narrow current RBAC; original actor and critical distinct eligible human retained. |

| Attribution could invent billable bytes or retroactive owner history | Typed measured sources, interval/version provenance, direct/estimated/residual arithmetic, unknown/stale/unsupported explicitly retained; no payments/FX. |

| Separate business decision might bypass critical operation approval | API explicitly requires existing exact-operation eligible critical approval; UI presents both requirements; submission/decision grants no execute rights. |
