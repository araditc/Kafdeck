## Merge discipline

Every workstream:
- starts from latest admitted prerequisite protected-main head,
- keeps Issue #146 reconciled,
- uses signed-off commits where repository policy requires,
- runs fresh exact-head applicable checks after source changes,
- addresses substantive deterministic review findings,
- resolves required threads,
- requires fresh CODEOWNER approval after head changes,
- merges only under `Protect main` with `expected_head_sha` equal to live PR head.

Dependency-valid stacked planning/design work may continue while review is pending, but blocked implementation dependencies may not be bypassed and no approval may be fabricated.

## Global stop conditions

Stop and request owner approval for:
- material expansion beyond Issue #145/RFC-0006,
- a new mutation class not represented in the accepted scope,
- weakening independent CRITICAL approval,
- generic provider/CLI/AdminClient execution,
- credential retrieval or durable plaintext SCRAM storage,
- unrestricted data transfer/exfiltration capability,
- a mandatory data-plane proxy,
- release/tag/publication,
- v0.7+ activation.
