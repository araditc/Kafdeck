API request schemas are taken from RequestDelegateFactory metadata; typed governance response schemas are generated by the actual `BearerFamilyOpenApi.Schema` producer. Generated OpenAPI fingerprints cover complete payload/response/error/status/security descriptions, rather than just paths. Authorization filters, CSRF metadata, conditional Program admission, serializer/parser/configuration and endpoint sources are conservatively frozen too. A change to those producers requires compatibility review even when it is harmless. Updating an expected fingerprint is a reviewed selection change, never proof by itself that behavior is compatible.

Unlisted/undocumented browser mutation/recovery/observation variants remain explicitly Experimental as enumerated. Their functionality and existing safety tests are retained. Stable selection does not grant new Bearer/CLI parity, independent managed-user APIs, provider support, effect permission or an approval bypass.

## What the checks prove

Four focused tests compare fresh compiled/producer observations to committed immutable expected files, verify documented-vs-mapped parity and uniqueness, and enforce closed MCP schemas/effect classification. Ordinary tests never rewrite expected files. Export is explicit to a separate directory via `KAFDECK_CONTRACT_EXPORT_DIRECTORY`; the test still fails when the admitted baseline is absent or differs. Review a prepared export and copy only explicitly admitted changes. Full canonical JSON/document identities and normalized UTF-8 source hashes are portable across CRLF/LF checkouts.

The mapping fixture never starts a listener, worker, database or provider and never invokes a handler or resolves its credentials. Service registrations distinguish real DI parameters from bodies; factories throw if any application service is resolved. It enumerates the maximal mapping, **not a simultaneously supported deployment profile** or fresh authentication/provider acceptance. Existing conditional routes, denial/CSRF, G01-G04, CLI/provider and G06 runtime evidence remain authoritative and are reused. Final automatic PR CI exercises the integrated suite normally; successful W82/load/install campaigns are not manually replayed.

Deliberate API selection removal, CLI exit reassignment, MCP effect reclassification and operator key removal are tested against the real comparison path, with original baseline bytes restored. All four must fail; clean originals must pass. [Admission evidence](evidence/v1.0-contract-admission-20261113.json) records counts, hashes and scope.
