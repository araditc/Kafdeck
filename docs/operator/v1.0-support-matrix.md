## Security-fix and maintenance table

| Topic | Accepted policy / final check |
| --- | --- |
| Maintained release line | Latest supported released minor and its current patch. The current stable release line is v1.0, starting with published 1.0.0. |
| Backport | Explicit source/branch selection and affected regression/security checks; no automatic backport or old-minor LTS obligation. |
| Vulnerability handling | Current candidate dependency/image/code/secret evidence; affecting Critical vulnerabilities and blocking findings prevent release. Severity alone is not a substitute for reachability and disposition evidence. |
| CodeQL dispositions | #9 token guard has committed HTTP evidence and a false-positive disposition. #3 schema planner has a [demonstrated false-positive review and nine focused cases](../security/schema-compatibility-codeql-review.md): the flagged helper formats a resource name; explicit authority and High risk remain. No rule or guard is suppressed. |
| Compatibility/deprecation | RFC-0010: major-version treatment of incompatible Stable changes; at least one minor and 90 days advance notice for planned removal. Closed schemas/enums retain their negotiated boundaries. |
| Service commitment | No automatic SLA, LTS, response-time or delivery-date promise. |
| Candidate security status | Empty GitHub Dependabot/secret alert lists are only a repository snapshot. The final media must carry its own source-bound scan/SBOM/provenance evidence. |
