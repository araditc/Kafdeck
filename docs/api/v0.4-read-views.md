# v0.4 Consumers, Schemas & Ecosystem Read Views API

All v0.4 product routes remain under `/api/v1` and use GET only.

Authorization is backend-authoritative:

- `consumer.read` for consumer group/member/offset/lag/diagnostics,
- `schema.read` for subject/version/reference/diff/compatibility views,
- `connect.read` for Connect identity/connectors/tasks,
- `ksql.read` for statement-free ksqlDB metadata surfaces,
- `catalog.read` for descriptive topic catalog metadata.

Collection routes perform an action/cluster preflight before upstream enumeration and filter each returned resource through the configured resource patterns. No v0.4 action grants `record.read` or `record.export`.

The OpenAPI snapshot is `docs/api/openapi-v0.4.json` and is served by Kafdeck at `/openapi/v0.4.json`.

No consumer offset, Schema Registry, Kafka Connect, ksqlDB, Kafka topic/configuration, or record mutation endpoint is introduced.
