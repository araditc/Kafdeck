## Execution matrix and gates

SQLite standalone and PostgreSQL/HA are mandatory where persistence exists. Actual OIDC/Keycloak lifecycle (expiry/revoke/current permissions) and automation principals are mandatory for effect authorization. Browser fixtures alone cannot prove real identity/broker effects. REST and CLI exercise each new supported family; UI completes operator journeys; existing Terraform/MCP effects test governance enforcement. Each risky path covers success, denied/cross-scope, stale/version conflict, unavailable authority, cancellation/timeouts and durable restart recovery where applicable.

Retain v0.8 release identity, architectural boundaries, mutation/compensation, notifiers/webhooks, CLI/provider, declarative and MCP safety, PostgreSQL/recovery and Keycloak acceptance. Record the exact capability-tested Kafka versions at execution; do not replace real current matrix evidence with a claimed future version. A changed shared kernel triggers its relevant regression and live scenarios, not merely new feature tests.

Evidence per row: acceptance ID, producer command/workflow/job, source SHA/tree, environment/tool/dependency versions, provider/platform/client, fixture provenance, expected/actual effects, passed/failed/skipped counts, duration, artifact hashes, cleanup and limitations. Sanitized TRX/browser traces/HTTP transcripts/database assertions/metrics traces are linked. Skips, helper-only checks and build-only output cannot close required real scenarios; overlapping totals are reported independently.

PR exit requires appropriate exact-head checks, substantive relevant review, fresh CODEOWNER approval and zero required unresolved threads. Workstream closure additionally requires successful applicable protected-main checks and a row-complete evidence ledger. W72 passes documentation/contract validation only; it must not report future runtime scenarios as passed. The integrated W82 packet enumerates every required producer, rejects missing/failed/skipped mandatory evidence and binds accepted main to artifact hashes before separate publication approval.
