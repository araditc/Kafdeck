# v0.8 Compensation and Safe-Inverse Contract

Status: **PROPOSED FOR GOVERNED PLANNING ADMISSION**

## Principle

Kafdeck does not offer a generic rollback button.

A compensation is a new governed mutation whose effect is intended to counter an earlier effect when a safe inverse can be proven from current state.

## Eligibility

An operation family may be compensatable only when all are true:

1. a typed inverse operation exists;
2. current state can be read and fingerprinted;
3. the inverse does not require reconstructing destroyed information Kafdeck does not possess;
4. provider semantics permit deterministic verification;
5. current policy/capability still allows the inverse.

## Examples

Potentially eligible after implementation evidence:

- some reversible configuration changes with known previous non-secret value;
- pause/resume where current identity/state makes the inverse safe;
- enable/disable bounded automation policies.

Not generically reversible:

- DeleteRecords / destroyed Kafka history;
- deleted topic data without an external backup;
- permanent Schema Registry delete;
- external side effects performed by connectors outside Kafdeck;
- already delivered notifications;
- ambiguous effects without stronger evidence.

## Compensation pipeline

`Select prior operation -> Re-read current state -> Build inverse preview -> Authorize -> Risk -> Confirm/Approve -> Durable new operation -> Execute -> Verify -> Audit`

The prior operation ID is evidence/context, not authority.

## Risk

Compensation risk is computed from the inverse effect and current blast radius. It is not automatically lower than the original risk.

CRITICAL inverse effects require distinct eligible approval.

## Drift

If current state differs from the exact state required for a safe inverse, compensation is Blocked/Stale and a new normal plan must be created.

## Ambiguity

An unresolved original external effect cannot be compensated until current evidence establishes what actually happened.

## UX

The UI may display:

- Compensatable;
- NotCompensatable;
- RequiresFreshPlan;
- BlockedByDrift;
- BlockedByUnknownEffect.

It must not label an operation "reversible" unless the current safe-inverse contract is satisfied.
